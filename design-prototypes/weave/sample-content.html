01 / TYPOGRAPHY

二级标题：给内容一个清晰的层次

上方的「文章排版样板」是本页的一级标题 H1，也是文章标题。正文以二级标题 H2 划分章节，三级标题 H3 组织章节内的细节。标题有不同的字号、字重与上下留白，让阅读可以自然地停顿。

三级标题：把一件事讲具体

中文正文使用系统无衬线字体，保持舒适的行距与适中的行宽。重点可以加粗，语气可以用斜体表达，链接使用克制的灰色。行内代码如 renderToString() 有单独的底色，帮助读者区分代码与正文。

好的排版，让内容容易被读懂，也让思考有地方停留。

02 / CODE

代码块：结构与颜色一起说明问题

代码保留缩进与换行，标注语言，并以不同颜色区分关键字、字符串和注释。长行可在代码块内横向滚动，不会撑开整篇文章。

go
package main

import "fmt"

// 让内容编译一次，让每次阅读保持轻量。
func main() {
    topics := []string{"技术", "阅读", "生活"}
    for index, topic := range topics {
        fmt.Printf("%02d · %s\n", index+1, topic)
    }
}
