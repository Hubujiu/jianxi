内容全部由 AI 经 MCP 上传和修改，后台负责设置、查看、预览确认和回滚。Google、英文 / 多语言、RSS、账号角色以及主题插件体系当前不做。

后端决策已补齐：AI 修改独立副本，上传并解析后生成新草稿；发布按明确变更清单，每文章 / 关于我保留当前 + 3 旧版。撤回可回滚或下架为草稿，永久删除物理清理系统内可恢复内容。图片支持 AVIF 等格式与外链，视频仅通过适配平台链接嵌入、不托管文件。备份完整恢复业务数据及第三方配置，沿用当前管理 token；旧会话与运行任务不复活。预览先构建，确认后只作服务端时间定稿再激活，恢复先隔离重建再切换。

AI 上传源内容，程序生成最终 HTML。公式、代码块与图表在发布前编译；Go 后端通过有界构建子进程调用固定渲染器。Mermaid 官方静态输出需要 Node 和浏览器组件，镜像体积与构建峰值有待原型实测，不能将新增方案描述为只有一个 Go 二进制。

间隙按本目录的产品范围自主设计与实现。
