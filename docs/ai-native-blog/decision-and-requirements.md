# 技术决策与实现边界

更新日期：2026-10-07。当前范围以 [产品需求确认稿](requirements.md) 为准。本文把已经确认的行为转为推荐架构；尚未创建产品代码、编译依赖组合或测量性能。

## 1. 架构结论

采用 **Go 单服务 + SQLite + 发布时生成静态 HTML + 本机 MCP 桥接**。公开文章及导航直接读取生成产物；后台设置、发布协调、搜索与第三方任务由同一个 Go 服务负责。面向国内，所有产品界面为中文。

内容全部由外部 AI 客户端经 MCP 上传和修改，后台提供配置、预览、发布确认、历史回滚与备份导入导出。网站运行时不调用模型，无须配置模型供应商。

AI 只提交固定字段元数据、受限 Markdown 和允许的媒体资源；文章页面 HTML、模板、CSS / JS 与公开文件路径均由程序控制。首版支持 LaTeX 公式、HTML / Markdown 及其他语言源码高亮、Mermaid 图，统一在发布前编译为静态结果。[内容编译与渲染](content-rendering.md)

```text
本机 Codex / Claude Desktop
       │ stdio
       ▼
同一可执行文件的 MCP 桥接命令 ── 管理 token / 私有连接 ──┐
                                                     ▼
浏览器后台 ── 同一 token 解锁 ──► Go 常驻服务
                                  ├─ 内容、修订、配置、任务 → SQLite
                                  ├─ 解析校验 / 内容编译 / 页面生成 → 不可变静态版本目录
                                  ├─ 公开 HTML / CSS / 图片 → 读者和爬虫
                                  ├─ 只读搜索 → 当前公开版本的搜索表
                                  └─ 百度推送、统计接入、报告导入 → 状态记录
```

“静态展示”适用于文章、首页、分类、标签和关于我。搜索结果是明确的动态只读页面，后台也是动态页面；二者使用 Go 模板，普通 HTML 表单即可工作。公开阅读不现场查询内容数据库、渲染 Markdown 或执行模型请求。

## 2. 推荐技术栈

| 层 | 推荐选择 | 原因与边界 |
| --- | --- | --- |
| 工具链 | 前次核查的 Go 1.27.1 候选，实施时锁定受支持的补丁版 | 具体依赖版本尚未组合编译 |
| HTTP | 标准库 `net/http` | 一个服务承载静态路由、后台及私有 API |
| 页面 | `html/template` + 原生 CSS | 固定布局，发布时生成公开页面；后台 / 搜索使用服务端模板 |
| 正文 | Markdown，Goldmark v1.8.6 候选 + 固定扩展 | 构建期生成 HTML、目录和正文纯文本；按 AST 拒绝普通原始 HTML，代码示例保留 |
| 代码 | Go Chroma 静态高亮 | HTML / Markdown / TeX 等围栏展示转义源码，不执行，不递归编译 |
| 公式 | KaTeX `renderToString` 的固定构建包装器 | 发布前生成 HTML + MathML；CSS / 字体自托管，只支持数学语法 |
| 图表 | Mermaid CLI 固定构建包装器 | 发布前输出 SVG，以图片嵌入；Node + 浏览器依赖只在构建时执行 |
| 存储 | SQLite，`modernc.org/sqlite` v1.60.1 候选 | 单站内容与任务持久化，候选驱动最低 Go 1.26；无需独立数据库服务 |
| MCP | 官方 `modelcontextprotocol/go-sdk` v1.8.0 候选 | 本机 stdio 桥接；实现时实测指定客户端协议兼容性 |
| 搜索 | SQLite FTS5 trigram + 短词字面包含回退 | 中文子串检索，无独立搜索服务或词典；短词查询有扫描成本 |
| 后台交互 | HTML 表单优先，少量原生 JS | 一个密钥解锁，无前端框架、账号系统或独立后台构建链 |
| 推送 | SQLite 持久队列 + Go worker | 异步、幂等、重试与失败原因展示 |
| 部署 | 一个 Go 常驻进程 / 一个容器 + 持久数据目录 + 渲染工具 | 公式 / 图表调用有界构建子进程；MCP 桥接由客户端启动，无独立 Node 后台服务 |

候选版本和替代方案的依据见 [技术栈比较](stack-evaluation.md) 与 [MCP 调查](mcp-research.md)。当前没有采用 Hugo / Astro 的额外构建程序，也没有采用浏览器端 Pagefind 搜索。若原型测试推翻性能或中文检索假设，再调整具体实现。

基础布局 CSS 压缩传输暂定不超过 20 KiB；代码高亮、公式 CSS / 字体、图表图片及第三方统计分别记录体积。文章和导航默认不下发 JS，公式 / 图表无需浏览器渲染脚本。统计启用后增加选定服务脚本，其体积和加载耗时单独记录。

新增静态富内容渲染后，部署包增加 Node、Mermaid CLI 与 Chrome / Chromium 等构建组件。Go 继续承担后端和发布协调；有图时按需启动子进程，并设置并发 / 内存 / 时间限制和内容 hash 缓存。在线接收文章的单容器必须保留这些组件，不能只在镜像构建阶段安装后删除。镜像体积、发布峰值内存及冷启动时间仍需实测。

## 3. 数据的唯一来源

SQLite 保存规范 Markdown、元数据、独立工作副本 / 上传解析状态、当前草稿、已发布修订、保留历史及业务任务。副本是工作数据，只有上传、解析校验及 CAS 提交成功后才成为新草稿；不能直接覆写草稿或线上内容。Markdown 导出是迁移和备份格式；公开 HTML、目录和搜索索引是可再生成的派生产物，不存在两份可以独立修改的正式内容。

分类、标签和公开配置也纳入候选 release 快照；公开改名 / 删除经 MCP 预览确认后生效。搜索索引不关联实时可变的分类名称，从而保持正文、列表和筛选同属一个公开版本。

| 对象 | 核心职责 |
| --- | --- |
| SiteConfig | 站名、主域名、说明、作者、中文语言、时区及页面配置 |

| Revision | Markdown、标题摘要、作者、SEO 字段、来源、内容 hash、公开时间与修订状态 |

| AboutContent | 个人介绍及关联资料，使用同样的草稿、预览、发布与历史方式 |
| Asset | 内容 hash、类型、尺寸、alt、引用关系及私有 / 公开状态 |

不建立跨语言文章组，也不生成多语言 URL 或 `hreflang`。文章和目录均使用 `lang=zh-CN`。首次发布时间稳定，实质内容变化才修改更新时间及 sitemap `lastmod`，重建、样式变化和推送重试不刷新所有文章时间。[Sitemap 协议](https://www.sitemaps.org/protocol.html)

## 4. 单管理 token

使用一个随机管理 token，拥有后台、MCP 内容与配置操作的全部权限。后台提交该 token 后建立 HttpOnly / SameSite 浏览器会话；MCP 桥接通过私有 API 的授权头使用同一 token。没有用户表、角色、客户端权限等级或第二个批准密钥。

私有认证配置保存 token 校验 hash 与失效代次，是运行时唯一权威来源；环境变量仅用于首次初始化。后台轮换和主机 CLI 恢复均更新同一配置，认证文件不随内容备份导入覆盖。浏览器后台 / 预览位于 `/admin/`，桥接建议调用 `/_control/` 私有应用 API；首版不提供公网 HTTP MCP endpoint。

浏览器会话和 MCP 请求都由服务端验证。远程控制接口使用 HTTPS 或 SSH 隧道；管理 token 不放 URL、公开资源或 localStorage。token 轮换后旧凭据及浏览器会话失效；失去 token 时由主机终端恢复，恢复能力来源于已有主机控制权。

“AI 写草稿、用户确认后发布”保留为操作约定与预览绑定步骤：确认明确的修订后才能发起相应发布，内容改变则重新预览。由于所有使用者持有同一 token，服务端不能证明确认者是本人，也不能声称 AI 在权限上没有发布能力。[完整 MCP 契约](mcp-research.md)

私密服务凭据只保存在管理存储，默认掩码；留空保留、明确删除。完整备份包含第三方凭据并标注敏感，整站恢复按包完整恢复；不含凭据的内容导出不能冒充完整备份。管理 token 和会话不迁移，恢复保留当前实例的管理 token 并使旧会话失效。

## 5. 预览、发布与搜索的一致性

1. MCP 获取 / 修改独立副本，上传后执行解析校验；携带基准修订、预期草稿修订和幂等键，成功后提交新草稿。解析失败保留上传及诊断，现有草稿不变。
2. 创建 ChangeSet，明确目标修订、taxonomy、公开配置、资源及受影响 URL；其他草稿或配置变更不自动加入。固定基准公开版本与相关输入修订。
3. 预览阶段构建整个候选站和对应搜索记录，完成正文、公式、图表、目录、链接、sitemap 与资源校验，固定内容 / 模板 / 编译器 / 配置 hash。待发布时间以程序控制的字段表达。
4. 用户确认该预览和变更清单；确认绑定内容 hash、预览 artifactHash 和时间定稿规则。发布检查确认、当前相关修订、active release、实例代次及幂等键。
5. 串行发布协调器填入本次发布操作时间及其直接派生字段 / 列表排序，不重编译正文、公式或图表；验证变化仅限规则允许范围，记录 finalArtifactHash 后封存不可变产物。失败不得改变公开时间。需要其他内容重建时重新预览确认。
6. SQLite 事务记录 active release、文章时间、搜索版本和 outbox；服务更新内存只读快照。请求开始时只捕获一次快照。公开时间取成功操作的定稿时间，另记实际激活时间，不把预览时间当成上线时间，也不承诺磁盘定稿和激活发生在同一时刻。
7. 验证实际公开域名可读对应版本后，推送任务才可执行。任务执行前再次检查当前 URL 是否仍公开、配置与实例代次是否仍有效；推送失败不撤销已经上线的文章。

文件系统、SQLite 和外部平台没有共同事务。SQLite 的 active release 是唯一激活权威，磁盘只保存已完成产物，不另设可独立决定上线版本的磁盘软链接 / 指针；内存快照可从数据库重建。先持久化产物再提交激活事务，启动时校验 manifest / finalArtifactHash；无法恢复已提交产物时明确报错，不能猜测磁盘最新目录为线上版本。构建失败保留旧站，激活中断按持久记录恢复。任何状态下都不能让未发布草稿进入公开站或搜索。

发布后搜索读取新 release 的索引；撤回和回滚走同一构建与激活路径。旧版搜索记录在在途请求结束并满足清理条件后删除，避免新页面显示旧正文或仍能搜索撤回文章。

内容编译先按 Markdown AST 区分普通正文、代码、公式和 Mermaid；HTML 示例只转义高亮，普通原始 HTML 拒绝。公式 / 图表使用固定版本及配置，不接受文章传来的初始化脚本、外部资源或工具命令。渲染失败或超出资源预算时返回位置化诊断并阻止发布，旧站保持可用。只有程序生成并验证的正文 HTML 能进入模板的内部可信渲染通道，AI 字段始终不直接转换为可信 HTML。

Goldmark 的默认行为是省略原始 HTML；本项目增加 AST 输入诊断而非直接依赖省略行为，以免作者误以为内容已经完整上线。HTML / fenced code 的独立节点和固定扩展能力依据 [Goldmark v1.8.6 文档](https://github.com/yuin/goldmark/blob/v1.8.6/README.md)、[固定版本 block AST](https://github.com/yuin/goldmark/blob/v1.8.6/ast/block.go)。

## 6. 中文搜索的具体选择

首版采用字面子串搜索，支持标题、摘要、正文与分类 / 标签名称匹配，并可按分类 / 标签筛选。查询按空白分为少量检索项，以 AND 组合；每项按 Unicode 字符计长：三个及以上字符使用 FTS5 trigram 的安全构造短语查询，一至两个字符在当前公开版本的规范纯文本上使用参数化字面包含匹配。用户输入不作为原始 FTS 表达式执行；`%`、`_` 和引号按字面处理。

SQLite `unicode61` 不提供现成中文分词；trigram 的 `MATCH` 不匹配不足三个字符的查询，所以短词必须有独立路径。短词回退有线性扫描成本，个人博客通过输入长度、分页、限频及查询超时控制，并用目标数据量实测。[SQLite FTS5 官方文档](https://sqlite.org/fts5.html)

相关性优先考虑标题命中，随后正文命中，同级按时间排序；片段由服务端生成并转义。此方案提供可解释的字面检索，不增加语义向量数据库。Pagefind 的中文分词方案及查询边界见 [技术栈调查](stack-evaluation.md)。

## 7. 历史、回滚与备份

每篇文章与关于我分别保留当前已发布版本 + 最近 3 个已发布旧版本；下架时保留最后公开版本及其 3 旧版。工作副本、上传、草稿、预览及整站制品单独清理，其他文章发布不挤占该内容历史。发布成功后实际裁剪超额历史正文，操作审计可继续保留无正文元数据。

回滚把保留版本的内容复制为一个新修订，预览确认后生成新的整站 release，保持文章 ID、当前 URL 和首次发布时间。当前分类或资源已不存在时先处理冲突。历史保留与静态制品清理是两件事，不能因为删除旧目录而删掉仍可回滚的图片。

回滚候选不覆盖 AI 工作副本和现有草稿，只改变选定内容。撤回可选回滚或下架为草稿；下架移除当前公开路由 / 索引，旧址 404，保留 ID / 时间 / 历史。永久删除走可恢复的清理任务：物理删除内容、副本、上传、草稿、历史、预览、旧制品、索引与独占资产，清理系统管理的含该内容备份及任务载荷；共享资产按其他引用保留。清理未完成不报告删除完成，不自动为此内容新建可恢复备份。外部已下载备份与第三方缓存不在本系统控制范围。详见 [删除范围](requirements.md#撤回与永久删除)。

完整备份包括一致性业务快照、媒体、Markdown / 元数据、工作副本与上传、草稿、保留历史、全部业务配置与第三方凭据、分析报告与证据、路由及历史操作 / 推送记录，记录格式版本、渲染器 / 规则版本与 hash。管理 token、会话及运行锁排除。外链保存引用，不包含远端媒体文件。生成的 HTML 和 SVG 是派生产物，导入必须从源文重新验证编译；未通过解析的上传作为私有工作数据恢复，不能阻止合法已发布内容的重建或被当作有效草稿。SQLite 在线备份采用正式 backup API 或一致性替代方法；WAL 模式下不能只热拷贝 `.db` 文件。[SQLite 备份](https://sqlite.org/backup.html)、[WAL](https://sqlite.org/wal.html)

整站恢复先在隔离候选验证、重建和预览，再确认覆盖全部业务数据并创建恢复前完整备份，最后激活；当前管理 token 保留。切换检查全站写入代次，草稿、设置、报告等并发写入都使旧恢复确认失效。数据切换和公开版本使用同一恢复事务 / 对账协议，不能直接覆写运行中的数据库。恢复历史记录并追加本次恢复事件，旧运行任务不重放；新实例代次废止恢复前确认、提交句柄和幂等重试。恢复后的主域名 / 渠道先核对，默认不自动推送。数据库快照和可读源文件必须由同一导出快照生成并交叉校验，不一致则拒绝。导出 / 导入文件通过鉴权接口传输，不塞入大型 MCP 响应。

## 7.1 媒体与外部嵌入

上传支持 PNG / JPEG / WebP / AVIF / GIF，按真实类型、大小和尺寸校验；资产 ID 在源文中稳定引用，上传格式不等于全部格式都有转码能力。外链图片采用 HTTPS 浏览器直连，不自动由服务器抓取或代理。允许结构化外部视频 URL，由明确平台适配器生成播放器并提供普通链接回退；不接收任意 iframe / HTML，不上传、托管、转码视频文件。程序生成播放器是固定渲染能力，不开放 AI HTML 输入。第三方播放器的网络 / 脚本依赖单列，私有预览默认展示占位链接；备份只保存外链引用。当前公开版本的引用清单决定内容资产的匿名访问，历史资产保持私有。

## 8. 国内发现与第三方分析

百度为首个推送适配目标；账号验证、实际接口与额度由用户后台配置。主域名、百度 token、连接验证、任务重试及脱敏状态形成完整闭环。国内必应 / IndexNow 是可选渠道，目前不计入必需首版范围。

第三方首版范围已经确定：访问统计；SEO / GEO 外部服务链接及报告导入。有已核实公开 API 和用户授权后再增加数据联通。百度统计是访问统计候选，具体服务尚待选择。

分别记录访问数据、搜索排名 / 曝光，以及 AI 提及 / URL 引用证据。没有可用资料时显示未知；平台接收 URL 不等于收录或引用。国内 AI 平台没有已核实通用逐 URL 提交通道，不能用一个 GEO 按钮承诺覆盖所有平台。[国内 SEO / GEO 与分析调查](distribution-research.md)

公开页面具备 title、description、canonical、作者与时间、与正文一致的 JSON-LD、sitemap、robots.txt、真实链接与状态码。RSS / Atom 当前不做；报告、凭据、草稿、私有资源与后台不进入公开索引。统计脚本只在配置启用后接入，不提供任意脚本插件市场。

## 9. 范围与交付验收

| 首版领域 | 已确认范围 |
| --- | --- |
| 阅读与检索 | 首页、文章、分类 / 标签总览与列表、关于我、搜索、目录、时间、404；公式、代码块与 Mermaid 静态渲染 |
| 内容入口 | MCP 上传文章、介绍和配图，分类标签管理，草稿及明确预览后发布 |
| 后台 | 单 token 解锁，站点及服务配置，预览确认，3 历史版本及回滚，备份导出 / 导入 |
| SEO 与分析 | 基础 SEO、百度推送配置及任务、访问统计接入、SEO / GEO 链接与报告导入 |
| 运行 | 单协调器、发布失败恢复、版本一致的搜索、旧 URL 处理与持久任务 |

定时发布、语义搜索、评论、读者注册、明暗模式、归档和置顶等按后续需求加入。Google、英文 / 多语言、RSS、主题插件与账号权限体系当前不做。

以下是原型完成后的检查目标，尚未达到或测量：

- 在 100、1,000、5,000 篇测试文章下测量构建时间、内存、普通读取及长短搜索的延迟；据结果决定是否需要增量生成。
- 分别测量含公式 / 图表文章的冷构建、缓存复用、峰值内存和镜像体积；验证错误源、超时、渲染配置越界及外部资源访问会被拒绝。
- 禁用 JS 验证正文、导航、目录、分页和搜索表单；启用统计时单独检查额外体积和国内访问耗时。
- 在构建、制品落盘、激活及公开验证阶段模拟中断，确认恢复不泄露草稿、不丢失已成功发布的内容。
- 并发更新与重复请求不能覆盖新修订、重复发文或重复推送；发布与搜索版本一致。
- token 轮换、备份恢复和保留版本回滚有效；损坏备份在覆盖前被拒绝。
- 不把第三方响应、没有依据的排名 / 引用或未经实测的性能写为验收通过。

详细逐项产品验收及仍需用户选择的内容见 [产品需求确认稿](requirements.md)。
